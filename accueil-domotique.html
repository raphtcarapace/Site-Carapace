Trois moments du quotidien

Des scénarios possibles selon les équipements retenus. Rien n'est automatique tant que ce n'est pas prévu dans votre devis.

Je pars de chez moi

L'alarme peut s'activer, les volets se fermer et le chauffage passer en mode réduit, si ces équipements font partie de l'installation retenue.

J'arrive

La serrure connectée peut s'ouvrir sans clé et les lumières s'allumer, lorsque ces fonctions ont été choisies avec vous.

Une alerte

Une notification peut arriver sur le smartphone, avec une image ou une vidéo si une caméra ou un détecteur avec photo est prévu.
